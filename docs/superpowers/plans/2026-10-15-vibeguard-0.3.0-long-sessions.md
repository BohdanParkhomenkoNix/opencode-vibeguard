# vibeguard 0.3.0 long sessions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Placeholders survive restarts and compaction through an encrypted store with sliding expiry, and values the model made up itself are neither masked nor blocked in that session and its subagents.

**Architecture:** `src/store.js` seals the placeholder map and the per-session origin records into one AES-256-GCM file and merges on save. `src/session.js` tracks last use instead of creation. `src/origin.js` keeps, per session, the hashes of values the model made up and the subagent links. `src/messages.js` walks a request in order and consults one predicate (`isModelMade`) that `src/guard.js` also uses. `src/index.js` wires it all to the OpenCode hooks.

**Tech Stack:** Node ≥ 20 ESM, `node:crypto` (HKDF, AES-256-GCM, HMAC), `node:test`, OpenCode 2.0.29 for end-to-end tests.

**Spec:** `docs/superpowers/specs/2026-10-15-vibeguard-0.3.0-long-sessions-design.md`

## Global Constraints

- No new dependencies; only Node built-ins.
- Code style as in the repo: ESM, no semicolons, double quotes, 2-space indent, short JSDoc on exported functions.
- A secret never appears in a log line, an error message or the store file in plain text.
- Store default path `~/.local/share/opencode/vibeguard.store`; `store_file: ""` turns the store off.
- AES key: `HKDF-SHA256(ikm = vibeguard.key, salt = empty, info = "vibeguard store v1", 32 bytes)`; envelope `{ "v": 1, "iv", "tag", "data" }` (base64).
- Saves at most once every 2 s; a corrupt store is renamed to `<store>.corrupt-<epoch ms>`.
- `session.ttl` default `30d`, counted from last use.
- Version 0.3.0.
- Mutation: N/A — the user excluded mutation testing in every vibeguard plan; no mutation tool in devDependencies.
- UI check: N/A — an OpenCode server plugin, nothing renders in a browser.

## Review Focus

- Two OpenCode processes (the service and `opencode run`) save the same store: neither loses the other's mappings. Pinned in Task 3 (merge on save) and Task 8 (a second plugin instance reads the first one's store).
- A process exits within 2 s of a change: the change still reaches the disk. Pinned in Task 3 (the first request saves at once, `flush`) and Task 8 (one `exit` listener flushes every saver).
- The key file was regenerated, so the store no longer decrypts: the plugin starts and keeps guarding. Pinned in Task 2 (another key moves the file aside) and Task 8 (a corrupt store still guards).
- An event without `sessionID`: behaviour is exactly 0.2.6. Pinned in Task 6 and Task 7.
- A store near `max_mappings` (100000 entries): save and load stay fast. Pinned in Task 3 (100000 mappings under 3000 ms).

```js
import { createHmac } from "node:crypto"

function sanitizeCategory(input) {
  const raw = String(input ?? "").trim()
  if (!raw) return "TEXT"
  const upper = raw.toUpperCase()
  const safe = upper.replace(/[^A-Z0-9_]/g, "_").replace(/_+/g, "_")
  if (!safe) return "TEXT"
  return safe
}

/** The 12-hex hash inside a placeholder, lowercased; undefined for anything else. */
export function placeholderHash(placeholder) {
  return String(placeholder).match(/_([0-9a-fA-F]{12})(?:_\d+)?__$/)?.[1]?.toLowerCase()
}

/**
 * Placeholder ↔ value map shared by every session of one OpenCode process.
 * - placeholder: __VG_<CATEGORY>_<hash12>__, hash12 = first 12 hex chars of HMAC-SHA256(key, value)
 * - a mapping lives while it is used: ttlMs counts from the last use; 0 (`session.ttl: "0s"`)
 *   means mappings never expire by age; maxMappings evicts the least recently used
 * - `dirty` is set by any change so the caller knows the store needs saving
 */
export class PlaceholderSession {
  /**
   * @param {{ prefix: string, ttlMs: number, maxMappings: number, secret: Uint8Array }} options
   */
  constructor(options) {
    const prefix = String(options?.prefix ?? "__VG_")
    this.prefix = prefix
    this.ttlMs = Number.isFinite(options?.ttlMs) ? Number(options.ttlMs) : 60 * 60 * 1000
    this.maxMappings = Number.isFinite(options?.maxMappings) ? Number(options.maxMappings) : 100000
    // The key comes from key.js: a random per-process key would change every placeholder
    // after an OpenCode restart, while the stored replies still hold the old ones.
    if (!(options?.secret instanceof Uint8Array) || options.secret.length !== 32) throw new Error("PlaceholderSession needs a 32-byte secret")
    this.secret = Uint8Array.from(options.secret)

    /** @type {Map<string,string>} */
    this.forward = new Map()
    /** @type {Map<string,string>} */
    this.reverse = new Map()
    /** @type {Map<string,number>} placeholder -> last use */
    this.used = new Map()
    this.dirty = false
  }

  drop(placeholder) {
    const original = this.forward.get(placeholder)
    this.forward.delete(placeholder)
    this.used.delete(placeholder)
    if (original !== undefined) this.reverse.delete(original)
    this.dirty = true
  }

  cleanup(now = Date.now()) {
    if (!Number.isFinite(this.ttlMs) || this.ttlMs <= 0) return
    for (const [placeholder, usedAt] of this.used.entries()) {
      if (now - usedAt > this.ttlMs) this.drop(placeholder)
    }
  }

  evictOldest() {
    let oldestPlaceholder = ""
    let oldestTime = Infinity
    for (const [placeholder, usedAt] of this.used.entries()) {
      if (usedAt >= oldestTime) continue
      oldestTime = usedAt
      oldestPlaceholder = placeholder
    }
    if (oldestPlaceholder) this.drop(oldestPlaceholder)
  }

  /** Renews a mapping; never moves its last use back. */
  touch(placeholder, now = Date.now()) {
    const usedAt = this.used.get(placeholder)
    if (usedAt === undefined || usedAt >= now) return
    this.used.set(placeholder, now)
    this.dirty = true
  }

  lookup(placeholder, now = Date.now()) {
    const original = this.forward.get(placeholder)
    if (original !== undefined) this.touch(placeholder, now)
    return original
  }

  lookupReverse(original, now = Date.now()) {
    const placeholder = this.reverse.get(original)
    if (placeholder !== undefined) this.touch(placeholder, now)
    return placeholder
  }

  knownEntries() {
    return this.reverse.entries()
  }

  hashOf(original) {
    return createHmac("sha256", this.secret).update(String(original)).digest("hex").slice(0, 12)
  }

  generatePlaceholder(original, category) {
    return `${this.prefix}${sanitizeCategory(category)}_${this.hashOf(original)}__`
  }

  set(placeholder, original, now) {
    this.forward.set(placeholder, original)
    this.reverse.set(original, placeholder)
    this.used.set(placeholder, now)
    this.dirty = true
  }

  /**
   * The same original always maps to the same placeholder.
   * @param {string} original
   * @param {string} category
   */
  getOrCreatePlaceholder(original, category) {
    const existing = this.lookupReverse(original)
    if (existing) return existing

    const now = Date.now()
    this.cleanup(now)

    if (Number.isFinite(this.maxMappings) && this.maxMappings > 0) {
      while (this.forward.size >= this.maxMappings) this.evictOldest()
    }

    const base = this.generatePlaceholder(original, category)
    const current = this.forward.get(base)
    if (current === undefined || current === original) {
      this.set(base, original, now)
      return base
    }

    // A hash12 collision: a _N suffix keeps placeholders unique.
    const withoutSuffix = base.slice(0, -2)
    for (let i = 2; ; i++) {
      const candidate = `${withoutSuffix}_${i}__`
      const prev = this.forward.get(candidate)
      if (prev === undefined || prev === original) {
        this.set(candidate, original, now)
        return candidate
      }
    }
  }

  /** [placeholder, original, lastUsed] for every mapping, for the store. */
  exportMappings() {
    return [...this.forward].map(([placeholder, original]) => [placeholder, original, this.used.get(placeholder)])
  }

  /**
   * Takes mappings from the store. An entry that conflicts with a mapping in memory (the same
   * placeholder for another value, or the same value under another placeholder) is skipped;
   * the same mapping keeps the later last use. Importing does not set `dirty`.
   */
  importMappings(entries) {
    if (!Array.isArray(entries)) return
    for (const entry of entries) {
      if (!Array.isArray(entry)) continue
      const [placeholder, original, usedAt] = entry
      if (typeof placeholder !== "string" || typeof original !== "string" || !Number.isFinite(usedAt)) continue
      const current = this.forward.get(placeholder)
      if (current === undefined) {
        if (this.reverse.has(original)) continue
        this.forward.set(placeholder, original)
        this.reverse.set(original, placeholder)
        this.used.set(placeholder, usedAt)
      } else if (current === original && usedAt > this.used.get(placeholder)) {
        this.used.set(placeholder, usedAt)
      }
    }
  }
}

export function getPlaceholderRegex(prefix) {
  const escaped = String(prefix).replace(/[.*+?^${}()|[\]\\]/g, "\\$&")
  // Pattern: __VG_CATEGORY_HASH12__ or __VG_CATEGORY_HASH12_N__
  return new RegExp(`${escaped}[A-Za-z0-9_]+_[a-f0-9A-F]{12}(?:_\\d+)?__`, "g")
}
```

```js
import { createCipheriv, createDecipheriv, hkdfSync, randomBytes } from "node:crypto"
import * as nodeFs from "node:fs"
import os from "node:os"
import path from "node:path"

export const STORE_VERSION = 1
const INFO = "vibeguard store v1"

/** The XDG data directory, not ~/.config where the key is: a dotfiles sync must not carry both. */
export function defaultStoreFile() {
  return path.join(os.homedir(), ".local", "share", "opencode", "vibeguard.store")
}

export function emptyPayload() {
  return { mappings: [], sessions: {}, handoffs: [] }
}

/** A key of its own for encryption, derived from the HMAC key, which is never used for it directly. */
function storeKey(secret) {
  return Buffer.from(hkdfSync("sha256", secret, Buffer.alloc(0), INFO, 32))
}

export function seal(payload, secret) {
  const iv = randomBytes(12)
  const cipher = createCipheriv("aes-256-gcm", storeKey(secret), iv)
  const data = Buffer.concat([cipher.update(JSON.stringify(payload), "utf8"), cipher.final()])
  return JSON.stringify({ v: STORE_VERSION, iv: iv.toString("base64"), tag: cipher.getAuthTag().toString("base64"), data: data.toString("base64") })
}

/** Error messages name what failed, never the bytes: the payload holds the secrets. */
export function open(text, secret) {
  let envelope
  try {
    envelope = JSON.parse(text)
  } catch {
    throw new Error("not a store envelope")
  }
  if (envelope?.v !== STORE_VERSION || typeof envelope.iv !== "string" || typeof envelope.tag !== "string" || typeof envelope.data !== "string") {
    throw new Error("not a store envelope")
  }
  let plain
  try {
    const decipher = createDecipheriv("aes-256-gcm", storeKey(secret), Buffer.from(envelope.iv, "base64"))
    decipher.setAuthTag(Buffer.from(envelope.tag, "base64"))
    plain = Buffer.concat([decipher.update(Buffer.from(envelope.data, "base64")), decipher.final()]).toString("utf8")
  } catch {
    throw new Error("cannot decrypt: corrupt file or another key")
  }
  let payload
  try {
    payload = JSON.parse(plain)
  } catch {
    throw new Error("bad payload")
  }
  const ok = payload && typeof payload === "object" && Array.isArray(payload.mappings)
    && payload.sessions && typeof payload.sessions === "object" && !Array.isArray(payload.sessions) && Array.isArray(payload.handoffs)
  if (!ok) throw new Error("bad payload")
  return payload
}

const codeOf = (error) => error?.code ?? "unknown error"

/**
 * The store on disk, or an empty one. A store that cannot be read as ours is moved aside and
 * the plugin starts empty: losing mappings only leaves placeholders unrestored, it leaks nothing.
 * `fs` and `now` are replaceable for tests only.
 */
export function loadStore(file, secret, { log = console.error, fs = nodeFs, now = Date.now } = {}) {
  let text
  try {
    text = fs.readFileSync(file, "utf8")
  } catch (error) {
    if (error?.code !== "ENOENT") log(`[vibeguard] store ${file} unreadable (${codeOf(error)}), starting empty`)
    return emptyPayload()
  }
  try {
    return open(text, secret)
  } catch (error) {
    try {
      fs.renameSync(file, `${file}.corrupt-${now()}`)
    } catch {
      // Gone already, or not ours to move: starting empty is still right.
    }
    log(`[vibeguard] store ${file} unreadable (${error.message}), moved aside`)
    return emptyPayload()
  }
}
```

```js
const isEntry = (entry) => Array.isArray(entry) && typeof entry[0] === "string" && typeof entry[1] === "string" && Number.isFinite(entry[2])

/**
 * Union of two payloads: an entry in either is kept with the later last use; a session's model
 * set is the union. Then everything unused for ttlMs is dropped and mappings are capped at
 * maxMappings, least recently used first, so a merge never brings back what expiry removed.
 * For a value under two placeholders, the first one seen wins (`a` before `b`).
 */
export function mergePayloads(a, b, { ttlMs = 0, maxMappings = Infinity, now = Date.now() } = {}) {
  const alive = (usedAt) => !(ttlMs > 0) || now - usedAt <= ttlMs

  const mappings = new Map()
  const placeholderOf = new Map()
  for (const entry of [...(a.mappings ?? []), ...(b.mappings ?? [])]) {
    if (!isEntry(entry)) continue
    const [placeholder, original, usedAt] = entry
    const current = mappings.get(placeholder)
    if (current) {
      if (current[1] === original) current[2] = Math.max(current[2], usedAt)
      continue
    }
    if (placeholderOf.has(original)) continue
    mappings.set(placeholder, [placeholder, original, usedAt])
    placeholderOf.set(original, placeholder)
  }
  const kept = [...mappings.values()].filter(([, , usedAt]) => alive(usedAt)).sort((x, y) => y[2] - x[2]).slice(0, maxMappings)
  kept.sort((x, y) => (x[0] < y[0] ? -1 : x[0] > y[0] ? 1 : 0))

  const sessions = {}
  for (const source of [a.sessions ?? {}, b.sessions ?? {}]) {
    for (const [id, record] of Object.entries(source)) {
      if (!record || !Number.isFinite(record.lastUsed)) continue
      const current = sessions[id] ?? (sessions[id] = { lastUsed: record.lastUsed, model: [] })
      current.lastUsed = Math.max(current.lastUsed, record.lastUsed)
      if (current.parent === undefined && typeof record.parent === "string") current.parent = record.parent
      const model = Array.isArray(record.model) ? record.model.filter((h) => typeof h === "string") : []
      current.model = [...new Set([...current.model, ...model])]
    }
  }
  for (const [id, record] of Object.entries(sessions)) if (!alive(record.lastUsed)) delete sessions[id]

  const handoffs = new Map()
  for (const entry of [...(a.handoffs ?? []), ...(b.handoffs ?? [])]) {
    if (!isEntry(entry)) continue
    const current = handoffs.get(entry[0])
    if (!current || entry[2] > current[2]) handoffs.set(entry[0], [entry[0], entry[1], entry[2]])
  }

  return { mappings: kept, sessions, handoffs: [...handoffs.values()].filter(([, , usedAt]) => alive(usedAt)) }
}

/**
 * Merges the store on disk into `payload`, writes the result aside with mode 0600 and renames
 * it into place: a reader never sees half a file, and another process's entries survive.
 * Returns what was written, for the caller to take back into memory.
 */
export function saveStore(file, secret, payload, { ttlMs, maxMappings, now = Date.now(), log = console.error, fs = nodeFs } = {}) {
  const merged = mergePayloads(payload, loadStore(file, secret, { log, fs }), { ttlMs, maxMappings, now })
  fs.mkdirSync(path.dirname(file), { recursive: true, mode: 0o700 })
  const tmp = `${file}.tmp-${process.pid}`
  fs.writeFileSync(tmp, seal(merged, secret), { mode: 0o600 })
  fs.chmodSync(tmp, 0o600)
  fs.renameSync(tmp, file)
  return merged
}

/**
 * Runs `save` at most once per intervalMs: the first request saves at once, requests inside the
 * window collapse into one trailing save. flush() saves now if a request is pending (on exit).
 * A failed save is logged by its code only and tried again on the next request.
 */
export function createSaver(save, { intervalMs = 2000, now = Date.now, setTimer = setTimeout, clearTimer = clearTimeout, log = console.error } = {}) {
  let last = -Infinity
  let timer = null
  let pending = false
  const run = () => {
    if (timer !== null) {
      clearTimer(timer)
      timer = null
    }
    pending = false
    last = now()
    try {
      save()
    } catch (error) {
      log(`[vibeguard] store save failed: ${error?.code ?? "unknown error"}`)
    }
  }
  return {
    request() {
      pending = true
      if (timer !== null) return
      const wait = last + intervalMs - now()
      if (wait <= 0) return run()
      timer = setTimer(run, wait)
      // The trailing save must not keep OpenCode alive; flush() on exit covers it.
      timer?.unref?.()
    },
    flush() {
      if (pending) run()
    },
  }
}
```

```js
/** OpenCode starts a subagent's first user message with this line, then the parent's prompt. */
export const SUBAGENT_PREAMBLE = "You are a subagent spawned by another session.\n"

/**
 * Which values the model made up, per session. A value is kept as the 12-hex HMAC a placeholder
 * carries (`hashOf`), never in plain text. A subagent session links to the session that spawned
 * it and sees its parent's values as made up too. `dirty` is set by any change.
 */
export class OriginTracker {
  /** @param {{ hashOf(value: string): string, ttlMs: number }} options */
  constructor({ hashOf, ttlMs }) {
    this.hashOf = hashOf
    this.ttlMs = ttlMs
    /** @type {Map<string, { lastUsed: number, parent?: string, model: Set<string> }>} */
    this.sessions = new Map()
    /** @type {Map<string, { parent: string, lastUsed: number }>} prompt hash -> parent session */
    this.handoffs = new Map()
    this.dirty = false
  }

  /** The session's record, created or renewed. */
  record(sessionId, now = Date.now()) {
    let record = this.sessions.get(sessionId)
    if (!record) {
      record = { lastUsed: now, model: new Set() }
      this.sessions.set(sessionId, record)
      this.dirty = true
    } else if (record.lastUsed < now) {
      record.lastUsed = now
      this.dirty = true
    }
    return record
  }

  markModelMade(sessionId, value) {
    const record = this.record(sessionId)
    const hash = this.hashOf(value)
    if (record.model.has(hash)) return
    record.model.add(hash)
    this.dirty = true
  }

  isModelMade(sessionId, value) {
    return this.isModelMadeHash(sessionId, this.hashOf(value))
  }

  /** Follows parent links; a cycle (only a corrupt store can hold one) ends the walk. */
  isModelMadeHash(sessionId, hash) {
    if (!hash) return false
    const seen = new Set()
    for (let id = sessionId; typeof id === "string" && !seen.has(id); id = this.sessions.get(id)?.parent) {
      seen.add(id)
      if (this.sessions.get(id)?.model.has(hash)) return true
    }
    return false
  }

  /** Called with the restored prompt of a `subagent` call, which is what the child receives. */
  addHandoff(prompt, parentId, now = Date.now()) {
    this.handoffs.set(this.hashOf(prompt), { parent: parentId, lastUsed: now })
    this.dirty = true
  }

  /** Links a session to its parent when its first user message is a prompt the parent handed off. */
  linkSubagent(sessionId, firstUserText) {
    if (typeof firstUserText !== "string" || !firstUserText.startsWith(SUBAGENT_PREAMBLE)) return false
    if (this.sessions.get(sessionId)?.parent !== undefined) return false
    const handoff = this.handoffs.get(this.hashOf(firstUserText.slice(SUBAGENT_PREAMBLE.length)))
    if (!handoff || handoff.parent === sessionId) return false
    this.record(sessionId).parent = handoff.parent
    this.dirty = true
    return true
  }

  cleanup(now = Date.now()) {
    if (!Number.isFinite(this.ttlMs) || this.ttlMs <= 0) return
    for (const [id, record] of this.sessions) {
      if (now - record.lastUsed > this.ttlMs) {
        this.sessions.delete(id)
        this.dirty = true
      }
    }
    for (const [hash, handoff] of this.handoffs) {
      if (now - handoff.lastUsed > this.ttlMs) {
        this.handoffs.delete(hash)
        this.dirty = true
      }
    }
  }

  exportState() {
    const sessions = {}
    for (const [id, record] of this.sessions) {
      sessions[id] = { lastUsed: record.lastUsed, ...(record.parent !== undefined && { parent: record.parent }), model: [...record.model] }
    }
    return { sessions, handoffs: [...this.handoffs].map(([hash, handoff]) => [hash, handoff.parent, handoff.lastUsed]) }
  }

  /** Takes state from the store, merged into memory; malformed entries are skipped. Does not set `dirty`. */
  importState({ sessions, handoffs } = {}) {
    for (const [id, record] of Object.entries(sessions ?? {})) {
      if (!record || !Number.isFinite(record.lastUsed)) continue
      const current = this.sessions.get(id) ?? { lastUsed: record.lastUsed, model: new Set() }
      current.lastUsed = Math.max(current.lastUsed, record.lastUsed)
      if (current.parent === undefined && typeof record.parent === "string") current.parent = record.parent
      for (const hash of Array.isArray(record.model) ? record.model : []) if (typeof hash === "string") current.model.add(hash)
      this.sessions.set(id, current)
    }
    for (const entry of Array.isArray(handoffs) ? handoffs : []) {
      if (!Array.isArray(entry)) continue
      const [hash, parent, usedAt] = entry
      if (typeof hash !== "string" || typeof parent !== "string" || !Number.isFinite(usedAt)) continue
      const current = this.handoffs.get(hash)
      if (!current || current.lastUsed < usedAt) this.handoffs.set(hash, { parent, lastUsed: usedAt })
    }
  }
}
```

```js
function learnFromViews(gap, patterns, session, skip) {
  const kept = []
  for (const view of escapedViews(gap)) {
    for (const { original, category } of matchesIn(view, patterns)) {
      if (skip(original)) continue
      const needles = [original, ...escapedForms(original)].filter((n) => gap.includes(n))
      if (needles.length > 0) kept.push({ original, category, needles })
    }
  }
  if (kept.length === 0) return new Map()

  const rawHits = new Set(matchesIn(gap, patterns).map((hit) => hit.original))
  const learned = new Map()
  const decoded = new Map()
  const placeholderOf = (original, category) => {
    if (!decoded.has(original)) decoded.set(original, session.getOrCreatePlaceholder(original, category))
    return decoded.get(original)
  }
  for (const { original, category, needles } of kept) {
    if (needles.includes(original) && !learned.has(original)) learned.set(original, placeholderOf(original, category))
  }
  for (const { original, category, needles } of kept) {
    for (const n of needles) {
      if (n === original || learned.has(n)) continue
      learned.set(n, rawHits.has(n) ? session.getOrCreatePlaceholder(n, category) : placeholderOf(original, category))
    }
  }
  return learned
```

```js
/**

 * what is left of the raw text. In the other order a rule whose class includes `/` masks only the
```

Replace `knownPass` with:

```js
/**
 * Replaces every value the session already knows, and every escaped form of it, with its
 * existing placeholder, longest first. A context rule (a lookbehind) learns a value from one
 * occurrence, but the same value turns up bare or escaped in tool output, and the guard blocks
 * any known value it finds. An entry `skipEntry` accepts (made up by the model here) is left.
 */
function knownPass(root, session, skipEntry = NEVER) {
  const originalOf = new Map()
  for (const [original, placeholder] of session.knownEntries()) {
    if (!original || skipEntry(original, placeholder)) continue
    originalOf.set(original, original)
    for (const form of escapedForms(original)) if (!originalOf.has(form)) originalOf.set(form, original)
  }
  if (originalOf.size === 0) return 0
  const known = knownMatcher([...originalOf.keys()])
  const placeholders = getPlaceholderRegex(session.prefix)
  return mapStrings(root, (text) => known.replaceIn(text, placeholders, (found) => session.lookupReverse(originalOf.get(found))), SKIP_KEYS)
}
```

Replace `redactRequest` with, and add `learnModelMade` before it:

```js
/**
 * Marks as made up by the model, in origin.sessionId, every rule match in root (the model's own
 * output) that is not a known secret, in the raw text and in its escaped views. Placeholders
 * are not scanned. Wrap a tool input as `{ input }` so every key of it is content.
 */
export function learnModelMade(root, patterns, session, origin) {
  const placeholders = getPlaceholderRegex(session.prefix)
  mapStrings(root, (text) => {
    mapGaps(text, placeholders, (gap) => {
      for (const view of [gap, ...escapedViews(gap)]) {
        for (const { original } of matchesIn(view, patterns)) {
          if (session.lookupReverse(original) === undefined) origin.tracker.markModelMade(origin.sessionId, original)
        }
      }
      return gap
    })
    return text
  }, SKIP_KEYS)
}

const isNode = (value) => value !== null && typeof value === "object"

/**
 * Redacts several trees of one request. Items are walked in order (system, then each message):
 * a value the model output before anyone sent it is made up by the model and left as it is in
 * this session; a value sent to the model first is a secret. Without `origin` (no session id)
 * nothing is model-made. The known-value pass runs only after every rule pass, because a bare
 * value can sit in a tree walked before the tree where a rule first learns it.
 * @param {unknown[]} roots
 * @param {{ sessionId: string, tracker: import("./origin.js").OriginTracker }} [origin]
 */
export function redactRequest(roots, patterns, session, origin) {
  const skip = origin ? (original) => origin.tracker.isModelMade(origin.sessionId, original) : NEVER
  const skipEntry = origin ? (_original, placeholder) => origin.tracker.isModelMadeHash(origin.sessionId, placeholderHash(placeholder)) : NEVER
  let changed = 0
  for (const root of roots) {
    const items = Array.isArray(root) && root.every(isNode) ? root : [root]
    for (const item of items) {
      if (origin && item?.role === "assistant") learnModelMade(item, patterns, session, origin)
      changed += rulePass(item, patterns, session, skip)
    }
  }
  for (const root of roots) changed += knownPass(root, session, skipEntry)
  return changed
}
```

```js
function leakIn(text, known, placeholderOf, patterns, session, madeHere) {
  const original = known.find(text)
  if (original !== null) {
    const placeholder = placeholderOf.get(original)
    session.touch(placeholder)
    return { category: categoryOf(placeholder, session.prefix) }
  }
  let category = null
  redactText(text, patterns, {
    getOrCreatePlaceholder(match, ruleCategory) {
      if (!madeHere(match)) category ??= ruleCategory
      return ""
    },
  })
  return category ? { category } : null
}

/**
 * Last line of defence before bytes leave the machine: anything the rules match, or any value
 * already known to be secret, in any string of the outgoing body, also with JSON escapes undone.
 * A string that is JSON with escapes is checked with them undone only, so a value whose own text
 * is an escape spelling (`C0rp\taxes!`) is not found where the string holds the decoded character.
 * A value the model made up in this session (`origin`) is no leak: the provider wrote it.
 * Reports the category only.
 * @param {{ sessionId: string, tracker: import("./origin.js").OriginTracker }} [origin]
 */
export function findLeak(bodyText, patterns, session, origin) {
  if (!bodyText) return null
  const madeHere = origin ? (value) => origin.tracker.isModelMade(origin.sessionId, value) : () => false
  const placeholders = getPlaceholderRegex(session.prefix)
  const placeholderOf = new Map()
  for (const [original, placeholder] of session.knownEntries()) {
    if (origin && origin.tracker.isModelMadeHash(origin.sessionId, placeholderHash(placeholder))) continue
    placeholderOf.set(original, placeholder)
  }
  const known = knownMatcher([...placeholderOf.keys()])
  for (const { text: raw, json } of stringsOf(bodyText)) {
    const text = raw.replace(placeholders, " ")
    const views = escapedViews(text)
    // JSON text with escapes is checked only with them undone: in the escaped spelling an escape
    // glues to its neighbour (`\n@pytest.fixture` reads as the email `n@pytest.fixture`), and in
    // `arguments` OpenCode writes that spelling itself, so the redaction never sees it to mask.
    for (const view of json && views.length > 0 ? views : [text, ...views]) {
      const leak = leakIn(view, known, placeholderOf, patterns, session, madeHere)
      if (leak) return leak
    }
  }
  return null
}
```

```js
import { loadConfig } from "./config.js"
import { findLeak } from "./guard.js"
import { loadKey } from "./key.js"
import { learnModelMade, redactRequest, restoreStrings } from "./messages.js"
import { OriginTracker } from "./origin.js"
import { buildPatternSet } from "./patterns.js"
import { restoreText } from "./restore.js"
import { PlaceholderSession } from "./session.js"
import { createSaver, loadStore, saveStore } from "./store.js"

const LOG = "[vibeguard]"

/** Session hooks that see an LLM request before it is sent: system and messages are redacted here. */
export const REQUEST_HOOKS = ["context", "title", "compaction", "generate"]

/** A secret never belongs in a query to a third-party search service. */
export const NO_RESTORE_TOOLS = new Set(["websearch"])

/** No readable body is an error, not an empty body: a guard that reads nothing checks nothing. */
async function bodyText(request) {
  if (request && typeof request.clone === "function") return request.clone().text()
  if (request && typeof request.text === "function") return request.text()
  if (request && typeof request.body === "string") return request.body
  throw new Error("vibeguard: cannot read the request body")
}

/** If OpenCode ever sends a request whose hook failed, it goes out empty, whatever shape it has. */
function block(event) {
  for (const key of ["system", "messages"]) {
    const value = event?.[key]
    if (Array.isArray(value)) value.length = 0
    else if (typeof value === "string") event[key] = ""
    else if (value !== null && value !== undefined) event[key] = []
  }
}

/** The text of the first user message: a subagent's is the preamble followed by its prompt. */
function firstUserText(messages) {
  const first = Array.isArray(messages) ? messages.find((m) => m?.role === "user") : undefined
  if (typeof first?.content === "string") return first.content
  return Array.isArray(first?.content) ? first.content.find((p) => p?.type === "text")?.text : undefined
}

/** One `exit` listener for every plugin instance: a pending save must reach the disk. */
const savers = new Set()
function flushOnExit(saver) {
  if (savers.size === 0) process.once("exit", () => { for (const s of savers) s.flush() })
  savers.add(saver)
}

function openStore(config, secret, session, tracker) {
  const payload = loadStore(config.storeFile, secret)
  session.importMappings(payload.mappings)
  tracker.importState(payload)
  const persist = () => {
    session.cleanup()
    tracker.cleanup()
    const state = { mappings: session.exportMappings(), ...tracker.exportState() }
    const merged = saveStore(config.storeFile, secret, state, { ttlMs: config.ttlMs, maxMappings: config.maxMappings })
    // Another process's entries become usable here too.
    session.importMappings(merged.mappings)
    tracker.importState(merged)
    session.dirty = false
    tracker.dirty = false
  }
  session.dirty = false
  tracker.dirty = false
  const saver = createSaver(persist)
  flushOnExit(saver)
  return saver
}

async function setup(ctx) {
  let state
  try {
    const config = await loadConfig(ctx?.location?.directory)
    if (!config.enabled) {
      if (config.debug) console.error(`${LOG} disabled (${config.loadedFrom || "no config"})`)
      return
    }
    const secret = loadKey(config.keyFile)
    const session = new PlaceholderSession({ prefix: config.prefix, ttlMs: config.ttlMs, maxMappings: config.maxMappings, secret })
    const tracker = new OriginTracker({ hashOf: (value) => session.hashOf(value), ttlMs: config.ttlMs })
    const patterns = buildPatternSet(config.patterns)
    state = { config, patterns, session, tracker, saver: config.storeFile ? openStore(config, secret, session, tracker) : null }
  } catch (error) {
    // Fail closed: a guard that cannot start must not let requests through unguarded.
    state = { error }
    console.error(`${LOG} setup failed, every request is blocked: ${error.message}`)
  }

  const ready = () => {
    if (state.error) throw new Error(`vibeguard: ${state.error.message}`)
  }
  const debug = (line) => {
    if (state.config?.debug) console.error(`${LOG} ${line}`)
  }
  /** No session id (an event shape OpenCode does not send today): nothing is model-made. */
  const originOf = (sessionId) => {
    if (typeof sessionId !== "string" || !sessionId) return undefined
    state.tracker.record(sessionId)
    return { sessionId, tracker: state.tracker }
  }
  const changed = () => {
    if (state.saver && (state.session.dirty || state.tracker.dirty)) state.saver.request()
  }

  for (const name of REQUEST_HOOKS) {
    await ctx.session.hook(name, async (event) => {
      try {
        ready()
        state.session.cleanup()
        state.tracker.cleanup()
        const origin = originOf(event.sessionID)
        // Before redaction, so a subagent's first message already sees its parent's values.
        if (origin) state.tracker.linkSubagent(origin.sessionId, firstUserText(event.messages))
        const replaced = redactRequest([event.system, event.messages], state.patterns, state.session, origin)
        debug(`kind=${name} replaced=${replaced}`)
        changed()
      } catch (error) {
        block(event)
        console.error(`${LOG} ${name} request blocked: ${error.message}`)
        throw error
      }
    })
  }

  await ctx.session.hook("http.request", async (event) => {
    ready()
    const leak = findLeak(await bodyText(event.request), state.patterns, state.session, originOf(event.sessionID))
    debug(`kind=${event.kind} guard=${leak ? "BLOCKED" : "clean"}`)
    changed()
    if (leak) throw new Error(`vibeguard: plaintext ${leak.category} in outgoing ${event.kind} request`)
  })

  await ctx.tool.hook("execute.before", async (event) => {
    ready()
    const origin = originOf(event.sessionID)
    // Read before restore: the input is still exactly what the model wrote.
    if (origin) learnModelMade({ input: event.input }, state.patterns, state.session, origin)
    if (!NO_RESTORE_TOOLS.has(event.tool)) {
      if (typeof event.input === "string") event.input = restoreText(event.input, state.session)
      else restoreStrings(event.input, state.session)
    }
    // The restored prompt is what the subagent receives as its first message.
    if (origin && event.tool === "subagent" && typeof event.input?.prompt === "string") {
      state.tracker.addHandoff(event.input.prompt, origin.sessionId)
    }
    changed()
  })
}

export { setup }
export default { id: "vibeguard", setup }
```

In `README.md` replace the paragraph that starts with `` `session.ttl` sets how long a mapping lives `` with:

```markdown
`session.ttl` sets how long a mapping may stay unused before it is dropped (default `30d`); every use renews it. `"0s"` means mappings never expire by age (`session.max_mappings` still applies and drops the least recently used).

Mappings survive restarts in `store_file` (default `~/.local/share/opencode/vibeguard.store`; `""` keeps them in memory only), so a placeholder that only a compaction summary still holds is restored for tools in a new process. Several OpenCode processes share the file; each save merges with what is on disk. The file is AES-256-GCM encrypted with a key derived from `vibeguard.key`, mode 0600, and lives apart from the key so a sync of `~/.config/opencode` does not carry both. The encryption guards against that one file leaking on its own (a sync or a backup without the key), not against a process that can read your whole home directory: such a process can read the key and OpenCode's own `opencode.db` too. A store that cannot be read is moved aside to `<store>.corrupt-<time>` and the plugin starts empty.
```

In `## Limits` add these two lines after the first bullet:

```markdown
- A value made up by the model (it first appears in the model's own output, for example in the content of a `write`) is not masked or blocked in that session and its subagents: the provider wrote it, so it is no secret to the provider. In every other session it is masked as usual. A value sent to the model first stays a secret even when the model repeats it.
- A subagent whose prompt cannot be matched to its parent's `subagent` call masks the values its parent made up; the session still works.
```
