# vibeguard 0.3.0 origin journal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Whether a value is model-made is decided per session (with its subagents) by where it was first seen in that session — the model's output or the input — and no longer by the shared placeholder map.

**Architecture:** `OriginTracker` (`src/origin.js`) gets a second hash set per session, `input`, and one lookup, `classOfHash`, that walks the parent chain; the nearest session holding the hash decides, input winning inside one session. `redactRequest` (`src/messages.js`) first classifies every item of a request in history order — assistant items as `model`, everything else as `input` — by rule matches and by values of the placeholder map, then masks as before. `execute.before` (`src/index.js`) marks every value it restores from a placeholder as `input`.

**Tech Stack:** Node.js ESM, `node:test`, no dependencies; e2e with real OpenCode and the mock provider in `test/helpers/`.

**Spec:** docs/superpowers/specs/2026-10-15-vibeguard-0.3.0-long-sessions-design.md (§1 payload, §3 Rule/Order, §4, §5; amended at 194b504 and after)

## Global Constraints

- No new dependencies; only Node built-ins.
- Code style as in the repo: ESM, no semicolons, double quotes, 2-space indent, short JSDoc on exported functions.
- A secret never appears in a log line, an error message or the store file in plain text; the journal holds 12-hex HMAC hashes only.
- Store envelope and version stay as they are (`"v": 1`); a session record without `input` reads as an empty `input`.
- A hash in both `model` and `input` of one session is `input`.
- The guard (`src/guard.js`) is not changed.
- Without a `sessionID` nothing is model-made and nothing is journaled: behaviour as 0.2.6.
- Version stays 0.3.0.
- Mutation: N/A — the user excluded mutation testing in every vibeguard plan; no mutation tool in devDependencies.
- UI check: N/A — an OpenCode server plugin, nothing renders in a browser.

## Review Focus

- A value that arrived as input only in an escaped spelling (`a@b.io` in a JSON tool result), then written plainly by the model: it is a secret, because classification decodes views. Pinned in Task 2.
- A subagent whose parent saw a value as input, and whose model then writes it: masked in the child (the parent's class is the nearest). Pinned in Task 1 (chain) and Task 2 (redaction).
- A request with a large placeholder map (100000 entries): classification adds one matcher build per request and must stay fast. Pinned in Task 2 (under 3000 ms).
- A store written before this change (no `input` field) loads and keeps working. Pinned in Task 1.
- A model-made value that contains a shorter secret: masked by the known pass and checked by the guard the same way, so the guard never blocks what redaction left. Pinned in Task 2.

```js
import { RENEW_STEP_MS } from "./session.js"

/** OpenCode starts a subagent's first user message with this line, then the parent's prompt. */
export const SUBAGENT_PREAMBLE = "You are a subagent spawned by another session.\n"

/**
 * The origin journal: per session, which values the model made up (`model`) and which reached
 * the model as input first (`input`). A value is kept as the 12-hex HMAC a placeholder carries
 * (`hashOf`), never in plain text. A subagent session links to the session that spawned it; a
 * class is looked up along that chain and the nearest session holding the hash decides. The first
 * sighting on a chain decides: a value the chain already holds is never written again. `dirty` is
 * set by any change; a renewal sets it only when it moves last use forward by RENEW_STEP_MS.
 */
export class OriginTracker {
  /** @param {{ hashOf(value: string): string, ttlMs: number }} options */
  constructor({ hashOf, ttlMs }) {
    this.hashOf = hashOf
    this.ttlMs = ttlMs
    /** @type {Map<string, { lastUsed: number, parent?: string, model: Set<string>, input: Set<string> }>} */
    this.sessions = new Map()
    /** @type {Map<string, { parent: string, lastUsed: number }>} prompt hash -> parent session */
    this.handoffs = new Map()
    this.dirty = false
  }

  /** The session's record, created or renewed; a renewal alone sets `dirty` as PlaceholderSession#touch does. */
  record(sessionId, now = Date.now()) {
    let record = this.sessions.get(sessionId)
    if (!record) {
      record = { lastUsed: now, model: new Set(), input: new Set() }
      this.sessions.set(sessionId, record)
      this.dirty = true
    } else if (record.lastUsed < now) {
      if (now - record.lastUsed >= RENEW_STEP_MS) this.dirty = true
      record.lastUsed = now
    }
    return record
  }

  /** Writes the value to one set of the session's journal unless its chain already holds it. */
  mark(sessionId, value, set) {
    const record = this.record(sessionId)
    const hash = this.hashOf(value)
    if (this.classOfHash(sessionId, hash) !== undefined) return
    record[set].add(hash)
    this.dirty = true
  }

  markModelMade(sessionId, value) {
    this.mark(sessionId, value, "model")
  }

  markInput(sessionId, value) {
    this.mark(sessionId, value, "input")
  }

  classOf(sessionId, value) {
    return this.classOfHash(sessionId, this.hashOf(value))
  }

  /**
   * "model", "input" or undefined. Follows parent links; within one session input wins (only a
   * merge of two stores puts a hash in both sets). A cycle (only a corrupt store can hold one)
   * ends the walk.
   */
  classOfHash(sessionId, hash) {
    if (!hash) return undefined
    const seen = new Set()
    for (let id = sessionId; typeof id === "string" && !seen.has(id); id = this.sessions.get(id)?.parent) {
      seen.add(id)
      const record = this.sessions.get(id)
      if (record?.input.has(hash)) return "input"
      if (record?.model.has(hash)) return "model"
    }
    return undefined
  }

  isModelMade(sessionId, value) {
    return this.isModelMadeHash(sessionId, this.hashOf(value))
  }

  isModelMadeHash(sessionId, hash) {
    return this.classOfHash(sessionId, hash) === "model"
  }

  /** Called with the restored prompt of a `subagent` call, which is what the child receives. */
  addHandoff(prompt, parentId, now = Date.now()) {
    this.handoffs.set(this.hashOf(prompt), { parent: parentId, lastUsed: now })
    this.dirty = true
  }

  /** Links a session to its parent when its first user message is a prompt the parent handed off. */
  linkSubagent(sessionId, firstUserText) {
    if (typeof firstUserText !== "string" || !firstUserText.startsWith(SUBAGENT_PREAMBLE)) return false
    if (this.sessions.get(sessionId)?.parent !== undefined) return false
    const handoff = this.handoffs.get(this.hashOf(firstUserText.slice(SUBAGENT_PREAMBLE.length)))
    if (!handoff || handoff.parent === sessionId) return false
    this.record(sessionId).parent = handoff.parent
    this.dirty = true
    return true
  }

  cleanup(now = Date.now()) {
    if (!Number.isFinite(this.ttlMs) || this.ttlMs <= 0) return
    for (const [id, record] of this.sessions) {
      if (now - record.lastUsed > this.ttlMs) {
        this.sessions.delete(id)
        this.dirty = true
      }
    }
    for (const [hash, handoff] of this.handoffs) {
      if (now - handoff.lastUsed > this.ttlMs) {
        this.handoffs.delete(hash)
        this.dirty = true
      }
    }
  }

  exportState() {
    const sessions = {}
    for (const [id, record] of this.sessions) {
      sessions[id] = { lastUsed: record.lastUsed, ...(record.parent !== undefined && { parent: record.parent }), model: [...record.model], input: [...record.input] }
    }
    return { sessions, handoffs: [...this.handoffs].map(([hash, handoff]) => [hash, handoff.parent, handoff.lastUsed]) }
  }

  /** Takes state from the store, merged into memory; malformed entries are skipped. Does not set `dirty`. */
  importState({ sessions, handoffs } = {}) {
    const hashes = (list) => (Array.isArray(list) ? list.filter((hash) => typeof hash === "string") : [])
    for (const [id, record] of Object.entries(sessions ?? {})) {
      if (!record || !Number.isFinite(record.lastUsed)) continue
      const current = this.sessions.get(id) ?? { lastUsed: record.lastUsed, model: new Set(), input: new Set() }
      current.lastUsed = Math.max(current.lastUsed, record.lastUsed)
      if (current.parent === undefined && typeof record.parent === "string") current.parent = record.parent
      for (const hash of hashes(record.model)) current.model.add(hash)
      for (const hash of hashes(record.input)) current.input.add(hash)
      this.sessions.set(id, current)
    }
    for (const entry of Array.isArray(handoffs) ? handoffs : []) {
      if (!Array.isArray(entry)) continue
      const [hash, parent, usedAt] = entry
      if (typeof hash !== "string" || typeof parent !== "string" || !Number.isFinite(usedAt)) continue
      const current = this.handoffs.get(hash)
      if (!current || current.lastUsed < usedAt) this.handoffs.set(hash, { parent, lastUsed: usedAt })
    }
  }
}
```

```js
/** The placeholder map's values and every escaped form of them, needle -> original. */
function knownNeedles(session, skipEntry = NEVER) {
  const originalOf = new Map()
  for (const [original, placeholder] of session.knownEntries()) {
    if (!original || skipEntry(original, placeholder)) continue
    originalOf.set(original, original)
    for (const form of escapedForms(original)) if (!originalOf.has(form)) originalOf.set(form, original)
  }
  return originalOf
}

function knownIndex(session) {
  const originalOf = knownNeedles(session)
  return { originalOf, matcher: knownMatcher([...originalOf.keys()]) }
}

/**
 * Replaces every value the session already knows, and every escaped form of it, with its
 * existing placeholder, longest first. A context rule (a lookbehind) learns a value from one
 * occurrence, but the same value turns up bare or escaped in tool output, and the guard blocks
 * any known value it finds. An entry `skipEntry` accepts (made up by the model here) is left,
 * and is left out of the matcher, as the guard leaves it out.
 */
function knownPass(root, session, skipEntry = NEVER) {
  const originalOf = knownNeedles(session, skipEntry)
  if (originalOf.size === 0) return 0
  const known = knownMatcher([...originalOf.keys()])
  const placeholders = getPlaceholderRegex(session.prefix)
  return mapStrings(root, (text) => known.replaceIn(text, placeholders, (found) => session.lookupReverse(originalOf.get(found))), SKIP_KEYS)
}
```

```js
/**
 * Writes the class of every value in root to the origin journal of origin.sessionId: "model" for
 * the model's own output, "input" for anything sent to it. A value is a rule match, in the raw text
 * or in an escaped view, or a value of the placeholder map in any escaped form (`known`, built once
 * per request). Placeholders are not scanned. A value the session's chain already holds keeps its
 * class. Wrap a tool input as `{ input }` so every key of it is content.
 * @param {"model" | "input"} kind
 * @param {{ sessionId: string, tracker: import("./origin.js").OriginTracker }} origin
 */
export function classify(root, kind, patterns, session, origin, known = knownIndex(session)) {
  const mark = kind === "model"
    ? (value) => origin.tracker.markModelMade(origin.sessionId, value)
    : (value) => origin.tracker.markInput(origin.sessionId, value)
  const placeholders = getPlaceholderRegex(session.prefix)
  mapStrings(root, (text) => {
    mapGaps(text, placeholders, (gap) => {
      for (const view of [gap, ...escapedViews(gap)]) {
        for (const { original } of matchesIn(view, patterns)) mark(original)
      }
      known.matcher.replaceIn(gap, placeholders, (found) => {
        mark(known.originalOf.get(found))
        return found
      })
      return gap
    })
    return text
  }, SKIP_KEYS)
}

const isNode = (value) => value !== null && typeof value === "object"
const itemsOf = (root) => (Array.isArray(root) && root.every(isNode) ? root : [root])

/**
 * Redacts several trees of one request. First every item is classified in history order (system,
 * then each message): an `assistant` message is the model's output, anything else is input, and
 * the first sighting in the session's chain decides. Then the rules and the known-value pass mask
 * everything but the values model-made in this session. Without `origin` (no session id) nothing
 * is classified and nothing is model-made. The known-value pass runs only after every rule pass,
 * because a bare value can sit in a tree walked before the tree where a rule first learns it.
 * @param {unknown[]} roots
 * @param {{ sessionId: string, tracker: import("./origin.js").OriginTracker }} [origin]
 */
export function redactRequest(roots, patterns, session, origin) {
  if (origin) {
    const known = knownIndex(session)
    for (const root of roots) {
      for (const item of itemsOf(root)) classify(item, item?.role === "assistant" ? "model" : "input", patterns, session, origin, known)
    }
  }
  const skip = origin ? (original) => origin.tracker.isModelMade(origin.sessionId, original) : NEVER
  const skipEntry = origin ? (_original, placeholder) => origin.tracker.isModelMadeHash(origin.sessionId, placeholderHash(placeholder)) : NEVER
```
